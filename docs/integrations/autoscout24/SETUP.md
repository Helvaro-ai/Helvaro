# AutoScout24 (seller profile): setup

1. Settings, Integrations, AutoScout24 (seller profile), Connect.
2. Paste the address of your own seller profile, e.g. `https://www.autoscout24.be/nl/verkopers/<your-name>`. Tracking parameters are removed.
3. Prefer the official route when available: an export from AutoScout24 or your DMS (provider Feed) is more stable.
