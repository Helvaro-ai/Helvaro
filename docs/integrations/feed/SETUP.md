# Feed / dealer website: setup

1. Ask your website builder or DMS vendor for the address of the stock export (CSV, XML or JSON, https only).
2. Settings, Integrations, Feed / dealer website, Connect. Paste the address and save. A first sync starts at once.
3. If the address contains a secret (key=, token=), it is used as given and shown masked afterwards.
4. Check the card: vehicle count, last sync, last error.
