# Feed / dealer website: limitations

- A feed can be behind: the dashboard shows freshness and the assistant stops confirming availability when it is too old.
- Only what the feed supplies is changed; a missing column never blanks a field.
- Reservations: understood if the feed has a status of reserved.
- No push; polling only (hourly).
- 5 MB maximum; more than 3000 vehicles in total stops the sync to avoid writing duplicates.
