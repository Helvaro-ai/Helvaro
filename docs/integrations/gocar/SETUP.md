# Gocar.be: setup

1. Only if you have an export (CSV, XML or JSON): Settings, Integrations, Gocar.be.
2. **Upload file**: pick the export. It is read the same way as a feed. Cars that were in an earlier upload and are missing now are marked sold, unless more than half would go: then you are asked to confirm first.
3. Or, if the export is reachable at an https address, Connect and paste the address; it is then read every hour.
