# Gocar.be

Provider id: `gocar` · Status: **MANUAL** · Auth: csv (an export address, no credentials)

No public dealer integration was found. If the dealer has an export of their Gocar.be stock, it goes through the same path as a generic feed.

**What it reads:** Reads the export at the address the dealer gives, like provider Feed. Status MANUAL means: no API, the dealer supplies the export.
